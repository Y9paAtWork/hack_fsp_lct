# NefteCode AI Operator

Веб-сервис для прогнозирования содержания серы, проверки технологических ограничений и безопасной оптимизации режима.

## Быстрый запуск

```bash
chmod +x start.sh
./start.sh
```

После запуска откройте:

```text
http://localhost:8501
```

## Что работает без полного датасета

В облегчённой конкурсной поставке доступны:

- системная страница;
- статичный демонстрационный сценарий;
- графики;
- JSON/PDF-отчёт;
- интерфейс AI Assistant;
- сохранённые модели Agent 1/2/3.

## Полный live-режим

Для live What-if и live optimization добавьте исходные данные соревнования:

```text
data/242000_tags.csv
data/avt_tags.csv
```

После этого перезапустите приложение.

## Архитектура

- Agent 1 — прогноз содержания серы;
- Agent 2 — проверка технологических ограничений;
- Agent 3 — TD3-оптимизация;
- Hybrid Router — быстрый детерминированный интерфейс запросов;
- Local LLM integration — опциональное расширение.

## Опциональная локальная LLM

Архитектура поддерживает локальную LLM, но веса модели не включены в конкурсный архив из-за ограничения размера.

Для Apple Silicon:

```bash
source .venv/bin/activate
pip install -r requirements-llm-macos.txt
```

После этого добавьте совместимые веса в каталог `llm/`.
