# FSP CAREER — React-прототип

Сайт создан по `FSP_CAREER_website_pages_spec.md` и фирменному стилю ФСП. Используются локальные логотипы и шрифты из `public/brand`.

## Запуск

Нужны Node.js 18+ и npm.

```bash
cd /Users/yaroslav/vscode/LCT/site
npm install
npm run dev
```

Откройте адрес Vite (обычно `http://localhost:5173`). Для готовой сборки: `npm run build`, затем `npm run preview`.

## Что доступно

- Лендинг и регистрация кандидата и работодателя.
- Кабинет кандидата: профиль, тесты, ежедневный тест, календарь активности, достижения, отдельные списки приглашений и откликов; каждый диалог открывается на отдельном экране.
- Кабинет работодателя: вакансии, выбор вакансии для подбора, топ‑20 кандидатов со схожестью 0–1, фильтры, список диалогов с кандидатами и отдельный экран чата.
- Демодиалоги и отправленные приглашения сохраняются в `localStorage` браузера и видны обеим ролям на одном устройстве. Для проверки общего диалога выберите первую вакансию и пригласите первого кандидата — это демонстрационный пользователь «Мария Орлова».

Все имена, вакансии, баллы, рейтинги, активность и результаты тестов — заглушки. При регистрации доступны 16 специализаций. API, авторизация, распознавание PDF, выполнение кода и реальная модель ранжирования не подключены. Пятый шаг регистрации кандидата отсутствует в макетах; после шага 4 есть переход в демо-кабинет. Исходные данные лежат в `src/data.js`.

### Если в текущей среде `node` и `npm` не находятся в PATH

```bash
cd /Users/yaroslav/vscode/LCT/site
PATH="/Applications/ChatGPT.app/Contents/Resources/cua_node/bin:$PATH" npm install
cp /Applications/ChatGPT.app/Contents/Resources/cua_node/bin/node /private/tmp/fsp-node
codesign --force --sign - /private/tmp/fsp-node
/private/tmp/fsp-node node_modules/vite/bin/vite.js --host 0.0.0.0
```
