# FSP CAREER

React-прототип платформы для кандидатов и работодателей. Интерфейс выполнен по приложенной спецификации и фирменному стилю ФСП.

## Требования

- Node.js 18 или новее
- npm

## Запуск

Выполняйте команды из корня репозитория:

```bash
npm ci
npm run dev
```

Откройте адрес, который выведет Vite.

## Сборка

```bash
npm run build
npm run preview
```

## Возможности прототипа

- Лендинг и регистрация кандидата и работодателя.
- Профиль кандидата, тесты, ежедневная практика, календарь активности и достижения.
- Отдельные списки приглашений и откликов. Каждый диалог открывается на отдельном экране.
- Выбор вакансии, подбор топ‑20 кандидатов с оценкой схожести от 0 до 1 и отправка приглашения.
- Демопереписка между ролями. Сообщения и приглашения сохраняются в браузере на одном устройстве.

## Деморежим

Имена, вакансии, оценки, активность и результаты тестов — заглушки. API, авторизация, распознавание PDF, выполнение кода и модель ранжирования пока не подключены. Пятый шаг регистрации кандидата отсутствует в макетах; после четвёртого шага доступен демо-кабинет.
