# FSP Career

Платформа подбора кандидатов по опыту и подтверждённым навыкам. В репозитории находятся React-интерфейс, FastAPI-сервер, каталог из 202 технологий, матрица грейдов и компактная демонстрационная SQLite. Рабочая база, личные данные и веса модели в Git не входят.

## Быстрый запуск

Из каталога `site/`:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r backend/requirements-embeddings.txt
npm ci
python -m backend.install_demo_db
npm run build
python -m uvicorn backend.app:app --host 127.0.0.1 --port 8000
```

Откройте `http://127.0.0.1:8000`. Команда установки демобазы не перезаписывает существующий `data/fsp.sqlite3`. Для разработки интерфейса можно отдельно запустить `npm run dev` и открыть `http://127.0.0.1:5173`.

При старте сервер загружает банк технологических и ежедневных вопросов из файлов `backend/technology_questions.json` и `backend/daily_questions.json`. Ответы проверяются на сервере.
Вопросы и ключи этой демонстрационной поставки открыты в Git; для реального подтверждения навыков потребуется закрытый банк заданий.

## Данные в Git

`data/demo_seed.sqlite3` — выборка из рабочей БД: **174 обезличенных резюме, 48 вакансий, 16 специализаций × 3 грейда**, 295 отдельных блоков опыта и готовые Jina-векторы для них и вакансий. В ней также находятся 1730 технологических и 106 ежедневных вопросов. Сохранены нормализованные стеки, грейды, демонстрационные показатели навыков, активности и достижений. Опыт резюме переписан без личных данных, после чего векторы пересчитаны. Импортированные кандидаты не имеют аккаунтов.

Демобаза копируется в рабочий файл `data/fsp.sqlite3`, который исключён из Git. Регистрация создаёт новые аккаунты в рабочей копии. Для пересборки выборки при наличии полной локальной БД и модели:

```bash
python -m backend.build_demo_seed --source data/fsp.sqlite3 --output data/new_demo_seed.sqlite3
```

Скрипт не меняет исходную БД и не перезаписывает существующий файл. Для публикации новой выборки её нужно проверить и заменить `data/demo_seed.sqlite3`.

## Поиск и модель

Демовакансии и резюме уже векторизованы. Для **новой вакансии**, поиска вакансий по **новому опыту кандидата** и оценки развёрнутых ответов нужна локальная `jinaai/jina-embeddings-v3`. Веса намеренно не включены в Git. Загрузите ревизию, ожидаемую кодом, в соседний каталог `models/jina-embeddings-v3`:

```bash
python - <<'PY'
from huggingface_hub import snapshot_download
snapshot_download(
    repo_id='jinaai/jina-embeddings-v3',
    revision='ab036b023d30b4d1138c4c3bfa9f0c445ab455d6',
    local_dir='../models/jina-embeddings-v3',
)
PY
```

Модель используется локально; при скачивании требуется интернет. Для автоматически проверяемых заданий на Python, JavaScript и SQL нужен запущенный Docker и отдельный worker:

```bash
docker pull python:3.11-alpine
docker pull node:20-alpine
export FSP_SANDBOX_SECRET='замените-на-длинный-случайный-секрет'
python -m backend.sandbox_worker
```

Тот же `FSP_SANDBOX_SECRET` должен быть задан серверу. Если worker недоступен, кодовое задание не получает оценку.

## Проверка сценариев

- **Кандидат:** зарегистрируйтесь, выберите специализацию и грейд, добавьте стек и опыт. Доступны тесты по технологиям, ежедневные вопросы, PDF резюме и поиск открытых вакансий.
- **Работодатель:** зарегистрируйте компанию и подтвердите её локальной командой `python -m backend.approve_employer email@example.org`. Создайте вакансию, заполните обязанности и запустите подбор. До согласия кандидата выдача обезличена.
- **Приглашения:** зарегистрированному кандидату предложение приходит в кабинет. Для демонстрационного резюме оно сохраняется в кабинете работодателя с пометкой «Не доставлено · нет аккаунта»; чат и полное резюме не открываются.

Алгоритм: сначала фильтр по специализации, грейду и обязательным технологиям; затем лучший отдельный блок опыта, вектор подтверждённых навыков, активность и достижения. Веса сейчас **70 / 25 / 2,5 / 2,5**. Дополнительные сведения об источниках вопросов — в [QUESTION_SOURCES.md](QUESTION_SOURCES.md).
