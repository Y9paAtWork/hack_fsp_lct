# Перенос актуальной БД поверх `fsp-database.zip`

Архив `fsp_current_delta_2026-10-11.zip` содержит новые и изменённые строки по сравнению с исходным `fsp-database.zip`. В том числе: зарегистрированные аккаунты и профили, зарплатные ожидания кандидатов, грейды вакансий, результаты тестов, активность, skill-векторы и все рассчитанные векторы вакансий. Старые описания импортированных резюме и вакансий повторно не упакованы.

## Сборка на другом устройстве

Положите рядом **исходный** `fsp-database.zip` и этот архив. Распакуйте из нового архива `transfer_current_db.py` и запустите:

```bash
python3 transfer_current_db.py assemble \
  --base-zip fsp-database.zip \
  --package fsp_current_delta_2026-10-11.zip \
  --output fsp.sqlite3
```

Скрипт проверяет контрольные суммы, целостность SQLite и соответствие исходного архива. Он не перезаписывает существующий `fsp.sqlite3`. Для сборки требуется около 5 ГБ свободного места. Готовую БД скопируйте в `site/data/fsp.sqlite3` при остановленном сервере.

Для сайта нужна версия кода с колонками `expected_salary_min`, `grade` и `required_technologies_json`. Архив также содержит `grade_matrix.json` и `technology_stack_FINAL.csv`; если этих файлов нет в коде на другом устройстве, положите их в `site/backend/`. Банк вопросов доступен отдельно внутри архива как `test_bank.sqlite3` и уже входит в собранную основную БД.

Сессии входа не переносятся: пользователям потребуется войти снова. Архив содержит профили и хеши паролей, поэтому передавайте его как приватный файл.

## Повторная выгрузка

Из каталога `site`:

```bash
python3 backend/transfer_current_db.py export \
  --base-zip ../fsp-database.zip \
  --current data/fsp.sqlite3 \
  --output out/fsp_current_delta.zip
```
