# Перенос данных пользователей и тестов

Нужны три файла:

- исходный `fsp-database.zip`;
- `fsp_user_delta.zip` — новые записи пользователей, грейды, векторы навыков, активность, результаты тестов и достижения;
- `fsp_test_bank.zip` — отдельная SQLite-база с 202 технологиями, 1 730 технологическими вопросами и 106 ежедневными вопросами.

В пользовательском архиве нет повторной копии старых резюме, вакансий и эмбеддингов. Он содержит только новые строки старых таблиц и данные таблиц, появившихся после исходного архива. Сессии входа не переносятся: на новом устройстве пользователям нужно войти снова.

## Сборка на другом устройстве

Распакуйте `fsp_user_delta.zip` в пустую папку. Рядом положите `fsp-database.zip` и `fsp_test_bank.zip`. Запустите из этой папки:

```bash
python3 transfer_compact_db.py assemble \
  --base-zip fsp-database.zip \
  --users-zip fsp_user_delta.zip \
  --tests-zip fsp_test_bank.zip \
  --output fsp.sqlite3
```

Полученный `fsp.sqlite3` можно положить в `site/data/fsp.sqlite3` проекта при **остановленном сервере**. Скрипт откажется перезаписывать существующий файл: для замены сначала переместите старый SQLite в резервную папку. Для сборки оставьте не менее 3 ГБ свободного места.

Если нужна только база вопросов, распакуйте `fsp_test_bank.zip`: файл `test_bank.sqlite3` открывается любым SQLite-клиентом. В основной базе после сборки вопросы также будут доступны в таблицах `test_questions` и `daily_questions`.

Пакеты не включают рассчитанные позже векторы **всех** вакансий из `vacancy_query_vectors`: они относятся к вакансиям, а не к перечисленным данным пользователей и тестам. В исходном архиве остаются прежние 2 616 векторов вакансий. Для полного поиска вакансий по резюме отдельный индекс вакансий нужно перенести или рассчитать заново.

Архив `fsp_user_delta.zip` содержит данные профилей и хеши паролей зарегистрированных аккаунтов; передавайте его как приватный файл.

## Повторная выгрузка

В текущем проекте пакеты можно пересобрать командой:

```bash
python3 backend/transfer_compact_db.py export \
  --base-zip ../fsp-database.zip \
  --current data/fsp.sqlite3 \
  --out-dir out/new_transfer
```
